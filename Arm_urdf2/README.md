# 🤖 arm1 - 5自由度机械臂MuJoCo模型 from Coolen

## 📋 项目概述

这是一个基于MuJoCo的5自由度机械臂仿真模型，由URDF文件转换而来。模型包含完整的物理属性、视觉网格和控制接口。项目提供多种控制模式和可视化工具。

### 模型规格
- **关节数量**: 5个旋转关节 (j1, j2, j3, j4, j5)
- **控制方式**: 位置控制
- **物理引擎**: MuJoCo
- **网格文件**: 6个STL文件

## 🚀 快速开始

### 环境要求
- Python 3.6+
- MuJoCo库
- macOS用户推荐使用mjpython（MuJoCo专用Python解释器）

### 安装依赖
```bash
pip install mujoco numpy
```

### 运行仿真

#### 方法1: 双模式终端控制（推荐）
```bash
# 使用mjpython运行（macOS推荐）
mjpython "joint_terminal_control.py"

# 或使用标准Python
python3 "joint_terminal_control.py"
```

**功能特性**：
- ✅ 双模式控制：串口控制模式 + Control窗口控制模式
- ✅ 实时可视化：MuJoCo查看器集成
- ✅ 终端交互：支持键盘命令输入
- ✅ 角度单位：自动处理度数与弧度转换

**控制命令**：
- `m1`: 切换到串口控制模式（终端输入）
- `m2`: 切换到Control窗口控制模式（MuJoCo界面）
- `q`: 退出程序
- 串口模式支持格式：
  - `关节编号 目标角度`（如：`2 45` 设置J2关节到45°）
  - `角度1,角度2,角度3,角度4,角度5`（5个关节角度值）

#### 方法2: 纯可视化查看器
```bash
mjpython "open_viewer.py"
```

**功能特性**：
- ✅ 纯可视化：仅显示机械臂模型
- ✅ 鼠标控制：支持视角旋转、缩放、平移
- ✅ 模型信息：显示关节、刚体、自由度等详细信息

#### 方法3: 其他控制脚本
```bash
# 串口控制模式
mjpython "joint_control_serial.py"

# 关节监控
mjpython "joint_monitor.py"

# 串口监控
mjpython "joint_monitor_serial.py"
```

### 模型转换
```bash
# 将URDF转换为MJCF格式
python3 "urdf_to_mjcf.py"
```

## 🎮 控制接口

### 双模式控制系统

#### 1. 串口控制模式（终端输入）
- **启动方式**: 程序启动后输入 `m1` 或默认启动
- **控制方式**: 通过终端输入关节角度
- **输入格式**: 
  - 单个关节: `关节编号 目标角度` (如: `2 45` 设置J2到45°)
  - 多个关节: `角度1,角度2,角度3,角度4,角度5` (逗号分隔)
- **角度范围**: -180° ~ 180° (自动转换为弧度)
- **控制算法**: 简单P控制 (增益系数20.0)

#### 2. Control窗口控制模式（MuJoCo界面）
- **启动方式**: 输入 `m2` 切换到此模式
- **控制方式**: 通过MuJoCo查看器的Control窗口直接控制
- **实时反馈**: 自动检测关节位置变化并打印当前位置
- **稳定检测**: 当关节到达目标位置时自动提示

### 实时监控功能
- **关节位置显示**: 每秒更新关节电机位置
- **目标检测**: 自动检测关节是否到达目标位置
- **状态提示**: 清晰的状态提示和错误信息

### 键盘控制命令
| 命令 | 功能 | 说明 |
|------|------|------|
| `m1` | 切换到串口控制模式 | 通过终端输入控制 |
| `m2` | 切换到Control窗口控制模式 | 通过MuJoCo界面控制 |
| `q` | 退出程序 | 安全退出所有线程 |
| `Ctrl+C` | 强制中断 | 紧急停止程序 |

## 📊 参数调优

### 控制参数
- **kp**: 位置控制增益 (默认50)
- **阻尼**: 关节阻尼系数
- **摩擦力**: 关节摩擦损失

### 修改参数
在 `arm1.xml` 文件中调整相应的数值：
```xml
<joint name="j2" damping="8.0" frictionloss="0.5"/>
<position joint="j2" kp="50"/>
```

## 🔧 常见问题

### Q: 网格文件缺失怎么办？
A: 确保所有STL文件都在 `meshes/` 目录下，文件名必须与模型中引用的一致。

### Q: 关节运动不稳定怎么办？
A: 调整阻尼和摩擦力参数，参考参数表中的阻力等级分类。

### Q: MuJoCo查看器无法启动怎么办？
A: 在macOS上推荐使用 `mjpython` 命令，而不是标准Python。如果仍然有问题，尝试使用 `mujoco.viewer.launch_passive()` 替代 `launch()`。

### Q: 终端控制程序无法响应输入怎么办？
A: 确保程序在正确的终端中运行，并且没有其他程序占用输入。程序使用非阻塞输入检测，支持实时键盘事件。

### Q: 如何切换控制模式？
A: 在终端中输入 `m1` 切换到串口控制模式，或输入 `m2` 切换到Control窗口控制模式。

### Q: 关节角度输入格式是什么？
A: 支持两种格式：
   - 单个关节: `关节编号 目标角度` (如: `2 45`)
   - 多个关节: `角度1,角度2,角度3,角度4,角度5` (逗号分隔)

### Q: 如何退出程序？
A: 输入 `q` 或按 `Ctrl+C` 安全退出程序。

## 💡 使用建议

## 📞 技术支持

### 常见问题解决

**Q: 图形界面无法打开？**
A: 在macOS上推荐使用mjpython模式：
```bash
./run_arm1.sh  # 然后选择模式3
# 或
./run_arm1_viewer.sh
```

**Q: 程序卡在启动界面？**
A: 检查是否已安装MuJoCo查看器，或尝试无界面模式：
```bash
echo "2" | python3 control_arm1.py
```

**Q: 关节运动异常？**
A: 检查参数配置，不同关节有不同的阻力等级：
- j2, j3: 超强阻力（阻尼8.0）
- j1, j5: 中等阻力（阻尼4.0）
- j4: 轻阻力（阻尼2.0）
